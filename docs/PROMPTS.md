# Как вести проект в Claude Code

Каждый этап начинай в новом окне Claude Code. Вся память проекта хранится в файлах `CLAUDE.md`, `docs/SPEC.md` и `docs/PROGRESS.md`, поэтому длинная переписка не нужна.

Ниже для каждого этапа есть готовый промпт: копируешь блок целиком и вставляешь. В начале каждого этапа проси Claude Code сначала показать план и только потом писать код.

---

## Подготовка (один раз, ~20 минут)

1. **Python 3.11** — ставить заранее не обязательно: `install.bat` сам найдёт его или предложит поставить через winget
   (нажать 1). Большая кнопка на python.org ставит другую версию — она не подойдёт.
2. **FFmpeg и Git** — открой PowerShell и выполни:
   ```
   winget install Gyan.FFmpeg
   winget install Git.Git
   ```
   Потом закрой и снова открой PowerShell.
3. Скачай проект из GitHub в `C:\AutoEditor` (путь лучше без кириллицы и пробелов). В PowerShell:
   ```
   git clone -b claude/admiring-rubin-1gaebd https://github.com/alexezkatka-dev/AiCut C:\AutoEditor
   ```
   Свежие изменения потом забираются командой `git pull` в этой папке.
4. В PowerShell выполни:
   ```
   cd C:\AutoEditor
   claude
   ```
5. В CapCut запиши его версию из настроек и **выключи автообновление**. Обновление CapCut может сломать формат черновиков.

## Этап 0 — проверка CapCut (1 вечер)

```
Прочитай CLAUDE.md и docs/SPEC.md. Начинаем этап 0 — проверка CapCut.
Моя версия CapCut: ВПИШИ_ВЕРСИЮ. Папка черновиков стандартная.
Создай .venv на Python 3.11, поставь pycapcut==0.0.4, сгенерируй тестовые клипы через FFmpeg
и создай тестовый черновик по примеру из SPEC §6: 2 клипа с обрезкой, зум, озвучка, надпись.
Сначала покажи план, потом делай. В конце скажи, что именно мне проверить в CapCut.
```

**Что проверить самому.** Перезапусти CapCut. В списке проектов должен появиться `AE_..._smoke`. Внутри: два клипа, на первом плавный наезд, звук на отдельной дорожке, надпись в начале.

**Если не открылся**, вставь:
```
Черновик не открылся. Что я вижу: ОПИШИ (ошибка, пустой проект, нет в списке).
Попробуй запасной путь из SPEC §6 — режим шаблона. Я сделаю в CapCut свой проект
с одним клипом, одной надписью и одной музыкой и скажу его имя.
```

## Этап 1 — каркас и сборщики (1–2 вечера)

```
Этап 0 пройден (см. PROGRESS.md). Начинаем этап 1 из SPEC §9.
Сделай каркас проекта по SPEC §8: install.bat, run.bat, requirements.txt с закреплёнными версиями,
config.example.yaml → config.yaml, Pydantic-модели плана (autoedit/plan.py),
сборщик CapCut и сборщик превью. Проверка — examples/edit_plan.example.json.
Подставь вместо исходников тестовые клипы. Сначала план.
```

**Что проверить.** `git pull`, `install.bat`, затем `example.bat`. Черновик открывается в CapCut,
а `work\example\preview.mp4` совпадает с ним по склейкам.

## Этап 2 — индексатор исходников (2–3 вечера)

Перед этапом скопируй 20–30 дублей с одной реальной съёмки в `C:\AutoEditor\samples\footage`.

```
Начинаем этап 2 — индексатор (SPEC §5.1, критерий в §9).
Реальные дубли лежат в samples\footage. Сделай индексацию и команду поиска по тексту,
чтобы я мог проверить: python -m autoedit.cli search "hand flipping chicken in a pan".
Сначала план.
```

Запуск: `git pull`, `install.bat`, `index.bat`, затем `search.bat` (спрашивает запросы по очереди).

**Что проверить.** Придумай 10 запросов на английском («hand cutting potato», «oil in pan» и т. п.). Нужный дубль должен быть в первой тройке хотя бы в 8 случаях из 10.

---

## Этап 3 — режим «Под озвучку» (3–5 вечеров)

Нужен один реальный ролик: сценарий в формате `examples/shot_list.example.md`, озвучка MP3 и все дубли. Сценарий в этом формате можно попросить у Claude в чате: «добавь строки SHOT на английском для Auto Editor».

```
Начинаем этап 3 — режим A (SPEC §5.2–5.4).
Сценарий: samples\НАЗВАНИЕ\shot_list.md, озвучка: samples\НАЗВАНИЕ\vo.mp3, дубли: samples\НАЗВАНИЕ\footage.
Сделай выравнивание озвучки, подборщик кадров и команду all, которая делает всё от индекса до черновика.
Сначала план.
```

**Что проверить.** Открой черновик, пройди по кадрам и посчитай, сколько кадров стоят правильно, а сколько пришлось менять. Напиши Claude Code обе цифры и время ручной доводки. Цель — не меньше 70% правильных кадров.

Сделай деление на сцены, описание сцен, редактирование слотов в окне и сохранение профиля темпа.

## Этап 6 — доводка

Выбирай по одному пункту за раз:
- приглушение музыки под голос;
- субтитры из озвучки;
- профиль темпа из референса для режима A;
- вертикальная версия 9:16 для Shorts;
- описание кадров через Claude API (платно, нужен ключ API).

---

## Если что-то сломалось

- Ошибку копируй целиком, вместе со строкой команды.
- После обновления CapCut сначала снова пройди этап 0, и только потом работай дальше.
- Если Claude Code уходит в сторону, напиши: «Вернись к CLAUDE.md, правило 1. Какой критерий у текущего этапа?»
