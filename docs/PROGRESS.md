## 2026-10-17 — этап 2: код готов, ждёт проверки на реальных дублях
- `autoedit/index/`: `probe` (ffprobe: длительность, fps, размер с учётом поворота, дата; хэш = размер+mtime+1 МБ),
  `frames` (кадры раз в 0,5 с шириной 384 через FFmpeg в память, `-hwaccel auto`; резкость, яркость, движение),
  `embed` (SigLIP ViT-B-16 webli через open_clip, на NVIDIA в fp16, иначе CPU; torch грузится только когда нужен),
  `takes` (рабочие участки: медиана из 3, движение между motion_min и shake, склейка пауз ≤ 1 с, мусор < 1 с — вон),
  `db` (SQLite: files / samples с эмбеддингом fp16 / takes), `indexer` (неизменённые файлы пропускаются без загрузки модели;
  удалённые из папки — убираются из индекса).
- `autoedit/search.py` + `cli search`: лучший кадр каждого дубля, топ-5, отчёт `work/<проект>/search.html` с миниатюрами.
- `index.bat` (samples\footage → проект samples), `search.bat` (без аргумента — спрашивает запросы по очереди, модель грузится один раз).
- Зависимости: torch 2.14.1 + CUDA 12.6 (для RTX 3050 Ti), open_clip 3.3.0, transformers (токенизатор SigLIP).
- Проверено здесь (CPU): 3 синтетических клипа — индексация 21 с (с загрузкой модели), повторный запуск 0,4 с;
  «a solid blue screen» → синий клип первым, «tv color bars test pattern» → клип с таблицей первым. 28 тестов проходят.
